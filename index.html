专栏开篇 · 一条向下的时间线

可可云(kekeyun) · 可可云

KEKEYUN

我不愿把品牌写成横幅。名字只有三个汉字，英文写作 kekeyun，适合被放进一条纵向的时间线里：先被看见，再被理解，最后才轮到价钱。下面不是创业史，也不是评测，只是按阅读顺序把这份页面该交代的事情排好。

01 / 命名

先把主语写清楚

可可云出现在标题里，是为了让后文有一个确定的人称。它在本页出售的是按月计算的用量份额、可同时在线的设备名额，以及写在档位里的线路权限。除此之外的身份、评级、节点规模，这篇专栏不掌握，也不补写。

02 / 抵达

从好奇走到对照表

多数人不是被一句口号说服的。他们先感到现有线路不够用，再开始并排放三份价钱。时间线走到这里，页面才允许出现数字。数字在后文「档位」一节，不提前剧透成广告。

03 / 带走

配置不在首页下载

本页没有安装包，也没有可点击的商店地址。订阅与配置文件应当在登录后的控制台生成，再交给你日常使用的工具。客户端一节会把这句话写得更冷、更完整。

04 / 停顿

读完问答再决定要不要付钱

专栏作者的习惯是把疑问留在接近结尾的位置。流量用尽会怎样、设备数如何清点、流媒体那一行究竟承诺了什么——凡是材料里没有的，我会直接写「本页不知道」。底部那条细导航，是给你中途跳页用的。

栏内笔记

如果把可可云只当成一个可被填写的订单，页面会写得很短。我更想先说明阅读契约：你看到的档位来自一份对照草稿，叙述口吻由我负责；你没有看到的公司执照、测速表、用户评语，一律当作不存在。

这篇页面答应写的

三档用量如何并列、年付与月付怎样同时出现、使用顺序如何从选档走到导入配置、以及一组按编号排列的问答。它们构成正文，而不是附录。

这篇页面拒绝写的

未提供的官方头衔、未核实的延迟数字、未给出的退款条款、未收录的客户端下载地址。缺席不是疏忽，是材料边界。

用量档位，逐行展开

对照不宜做成三块并排的橱窗。下面改成纵向清单：每一档先报名字与月费，再把年付注在下一行，权益按条目往下摊开。若你只想读一档，旗舰版被我单独做了色条加厚——那是排版上的停顿，不是替你做决定。

基础版

¥15 / 月

若按年结算，页面记作 ¥150 / 年。

  1. 每月计入 100GB 用量，用尽规则以控制台为准，本页不另编。
  2. 同一时段最多 3 台设备保持在线。
  3. 流媒体一项写作「基础解锁」，覆盖范围随线路变化，此处不做片源清单。
  4. 节点来自普通线路池，没有单独标明的专线字样。

旗舰版

本页加厚的一档

  4. 含 IPLC 专线方向的游戏延迟优化，具体游戏名单未附在材料里。

  4. 支持企业向的定制路由，如何提交需求，请走工单或客户经理，不在本页填表。

三档价格与条目依据对照草稿整理，并非现场询价。若控制台显示不同数字，以控制台为准。本页不设置支付入口，也不模拟交易链接。

使用说明：仍按时间顺序

说明书可以冷静，专栏可以把冷静写成步骤。以下五步没有「立刻开始」之类的催促，只是把一个人从阅读走到可用，中间必须经过的停靠站写全。

  1. 把档位读成自己的用量

    先估计一个月大概会消耗多少，再看设备是不是超过三台。数字对不上时，不要用形容词给自己打气，直接换一档或暂缓。

  2. 离开本页去登录

    可可云的账号流程不发生在这篇 HTML 里。这里没有表单，也就不会收下你的密码。登录地址以你自己保存的入口为准，本页不编造域名。

  3. 在控制台生成订阅或配置文件

    这是材料里唯一合理的「带走」方式。复制链接、导出文件、扫描二维码——具体哪一种，以控制台当时提供的为准。

  4. 导入你已经在用的工具

    兼容清单没有随材料送达，因此我不罗列软件名，以免写成虚假适配。你平日能读订阅的工具，通常就是这一步的目的地。

  5. 回头看用量与设备，而不是看心情

    连接是否可用，只能由你自己的环境回答。专栏能提醒的只有两件事：流量是按月记账的，设备数是同时在线的上限。

客户端：本页留白的那一栏

对照草稿没有给出任何客户端名称、版本号或下载地址。按照约定，缺地址就留空，不伪造商店链，也不画安装按钮。

你实际会去哪里取软件

登录后的控制台。那里如果出现订阅导入说明、配置文件或二维码，那才是可可云为当前账号准备的出口。本页的任务是告诉你出口不在这里。

若控制台也没有说明

把问题写成工单。旗舰版与团队版在档位里提到了优先或专属支持，基础版未写同等字样。等待回复期间，不要从来路不明的网盘获取所谓「官方包」。

url 一项：空字符串。这不是排版疏漏，是没有可核验来源时的唯一诚实写法。

常见问题，按编号排列

问答不折叠、不分组、不做成对话气泡。编号是为了让你在工单里可以引用「第 04 问」，也是为了让专栏的语气保持像在批注一份手稿。

  1. 可可云必须按年付吗？

    不是。三档都同时写出了月费与年费。年费在草稿里分别是 150、350、850 元，相当于少记两个月的月费，但本页不把它解释成限时活动。选哪一种结算，只影响你自己的日历。

  2. 流量用完以后会停，会限速，还是会自动续一笔？

    材料没有写。这是本页不能替你填写的空白。使用说明里把它推回控制台，问答里再重复一次：在看到官方规则之前，请按「用量是有上限的」来规划，而不是按猜测来规划。

  3. 「同时在线」的设备数，是累计绑定，还是当下连接？

    草稿用的是「同时在线」。按字面，它约束的是同一时刻，而不是历史绑定总数。若控制台另有设备管理页，以那一页的计数为准。超出上限时的表现（踢下线、拒绝握手、仅告警）同样未记载。

  4. 为什么首页不放安装包？

    因为没有可核验的下载地址。把一个按钮画出来却指向空链，或指向杜撰的文件，都比留白更不负责任。客户端一节已经把路指回控制台。

  5. 基础版的「基础流媒体」和旗舰版的「原生解锁」差在哪里？

    差在档位自己的用词，以及旗舰版把范围写成全节点。专栏没有片源测试表，因此不能说某个站点在某一档一定能打开。它只能告诉你：若流媒体是刚需，草稿把更完整的那句写在了旗舰版。

  6. 团队版的定制路由要提交什么？

    材料只说支持企业定制路由，并配有专属客户经理。需要的网段、域名清单、生效时间，本页无从代拟。适合把它当成一封工单的主题，而不是一篇自助教程的步骤。

  7. IPLC 那一行是不是等于游戏一定更顺？

    旗舰版把 IPLC 写作面向游戏延迟的专线优化。专线是线路种类，不是比赛结果。没有延迟样本、没有游戏名单，我就把这句话停在「档位里有它」，而不是写成体验承诺。

  8. 读完这条时间线，下一步该点哪里？

    若档位已经够用，离开本页，去你保存的登录入口。若仍有规则不清，先写工单，再付钱。底部导航可以把你送回开篇、档位或这一组编号——它固定在屏幕下沿，是为了让长文不至于迷路。

栏外

时间线在这里收住。可可云三个字从首屏的标题走到栏外，中间经过笔记、三档价钱、五步说明、一栏空白的客户端，以及八条编号问答。若你觉得还不够像一份产品页，那正是这篇专栏有意保持的距离。
